# Stride
Single-file daily tracker for product & growth partnerships. Open `index.html`; data stays in localStorage.
**Principle: value, not volume.** Max 3 bets a day. A bet scores by what changed (0 nothing, 1 moved forward, 2 milestone + proof, 3 real result + number + proof). Task counts are never scored.
- Captain View: weekly rating, needle days, moved rate, forecast honesty, results, partners moved, funnel, partner board, live pipeline, heatmap, auditable day log.
- `flow/build_snapshot.js`: code step of the viaSocket flow that builds `pipeline.json` (counts + partner names only).
Live: https://stride-daily.embarko.app. A viaSocket challenge entry, not regular work.
