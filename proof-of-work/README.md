# Proof of Work
Single-file daily task manager built to answer "how can my work be measured?". Open `index.html` — no build step, data stays in localStorage.
- **My Day**: commit to tasks (effort 1–5 + time estimate), focus timer, proof note on completion, slips are logged when you roll a task over.
- **Captain View**: score ring, delivery rate, estimate honesty, focus hours, slips, streak, 17-week heatmap, category split, per-day log with proof.
- **Share**: copies a read-only snapshot link (data is embedded in the URL hash) for your manager.
